# artefactos/

Aquí viven los artefactos generados durante la investigación: diagramas SVG, páginas HTML
interactivas, scripts JS/Python de análisis o visualización.

**Reglas (ver CLAUDE.md):**

1. Cada artefacto guarda, como comentario interno, **el prompt que lo produjo** y la fecha.
2. Diagramas conceptuales e ilustraciones: permitidos, **declarados como generados** en el pie.
3. Gráficos de datos: solo a partir de datos reales de `datos/`, con el código que los
   produce guardado aquí mismo. Nunca fabricar ni alterar imágenes de apariencia científica.
4. Pedir siempre SVG **editable** (no imagen rasterizada): permite corregir, traducir y
   adaptar sin regenerar.

**Ejemplos de prompts para artefactos de alta calidad visual:** ver la sección
"Agentes y artefactos" del tutorial (`index.html`) y `prompts/registro_prompts.md` (P6).
