La tesis de esta charla: tratar la investigación como un proyecto de software la mejora — y los agentes hacen esas prácticas accesibles sin ser programador.

Las opciones sobre la mesa

¿Por qué VS Code + Claude Code?

Chatbots con "proyectos"

ChatGPT Projects · Claude.ai · NotebookLM

Guardan documentos y conversaciones en la nube, pero no trabajan sobre los archivos del proyecto ni dejan rastro reproducible.

Agentes de código

Claude Code · Codex · Antigravity · Copilot

Leen y escriben el proyecto, ejecutan búsquedas y scripts, verifican — bajo reglas persistentes. Aquí viven las buenas prácticas.

La pieza que lo cambia todo

El arnés: CLAUDE.md

Un archivo de texto que el agente lee al empezar cada sesión.
Ahí viven tus reglas innegociables:

Nunca inventes referencias

Todo con DOI verificado y URL de acceso explícita. Lo no verificable se marca PENDIENTE.

Si no sabes, dilo

"No encontré evidencia" es una respuesta válida. Nunca rellenar con texto plausible.

Todo queda registrado

Cada búsqueda en datos/ con fecha, ecuación y conteos. Cada prompt en su registro.

Todo texto es borrador

Se marca [BORRADOR-IA] hasta que el investigador lo reescribe y lo firma.

Sin reglas explícitas, la velocidad multiplica también los errores.

Equivalentes: AGENTS.md en Codex (estándar abierto) · GEMINI.md en Antigravity. Este ejercicio: Claude Code + CLAUDE.md.

Parada 4 · La autoría

Cuatro modos de escribir con IA
sin dejar de ser el autor

4.1 Escritura directa + IA validadora

Tú escribes; la IA critica lógica y estilo. ⚠️ Nunca pegues datos sensibles sin anonimizar.

4.2 El diálogo como ejercicio autoral

"Hazme preguntas", "dame el contraargumento más fuerte". Pensar con la IA es legítimo: decides tú.

4.3 Los artefactos adecuados

Pídele estructuras, matrices, diagramas, código. No le pidas texto final sin revisar ni referencias "de memoria".

4.4 Principios de las imágenes

Conceptuales: sí, declaradas. De datos: solo desde datos reales. De apariencia científica: nunca.
